# Sichtprüfung der Abschnitte (Stand 15.11.2026)

Jeder Fall aus `daten/abschnitte.csv` wurde als Kartenausschnitt gezeichnet und einzeln angesehen. Die Blätter sind Screenshots; je Blatt vier Fälle (links oben, rechts oben, links unten, rechts unten).

**Legende:** rot = zugeordneter Weg; rosa mit dicker roter Linie = Teilstück (grüner Punkt = von, schwarzer Punkt = bis); gelb = Weg mit dem Straßennamen, nicht zugeordnet; grau = übrige Wege (gestrichelt = unbenannt); blaue Punkte mit Nummer = Adressen mit `addr:street` gleich Straßenname; graue Punkte = Adressen anderer Straßen; rote Zahl am Weg = OSM-Weg-ID.

Die Karten sind aus OSM-Rohdaten gezeichnet (OSM-API, Stand 15.11.2026), nicht aus dem Hintergrundbild einer Online-Karte.

## Nachbau
Die Blätter entstanden im Browser mit der OSM-API: pro Fall `way/ID/full.json` für die zugeordneten Wege und `map.json?bbox=` für Umgebung und Adressen, als SVG gezeichnet. Adressen gelten als „eigene Straße“, wenn `addr:street` (normalisiert, ohne Leerzeichen, Bindestriche und Punkte, „str“ am Ende als „strasse“) dem Straßennamen entspricht.
